# Omar Mohamed Anwar — portfolio

Static website. No build step, no dependencies, no accounts.

## Files
- index.html — entry point
- styles.css — design tokens and components
- site.css — page styles
- script.js — subtle scroll reveal
- assets/omar.jpg — profile photo

## Run locally
Open index.html in a browser.

## Deploy
- GitHub Pages: push these files to a repository, then Settings -> Pages -> Branch: main, folder: / (root).
- Netlify / Vercel: drag this folder into the dashboard, or connect the repository. No build command; publish directory is the folder root.

The fonts (Cormorant Garamond, Lora) load from Google Fonts, so keep the site online for the intended typography.
